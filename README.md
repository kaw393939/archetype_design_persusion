# Brand Archetypes, Design, and Persuasion

**Build a shared reference guide in a team of four.** Explain the topics, show examples, and use GitHub issues and pull requests to work together.

## What to make

| Section | Required work |
|---|---|
| [Archetypes](archetypes/README.md) | 12 pages; two original design examples per archetype, with a third optional |
| [Persuasion](persuasion/README.md) | 7 pages; an explanation and application example for each principle |
| [Modernist design](modernism/README.md) | 6 style pages with historical examples and sources |
| [Postmodernist design](postmodernism/README.md) | 6 style pages with historical examples and sources |
| [About the team](members/README.md) | One About page per person, including links to their issues |

## Start here

1. [Read the assignment](assignment.md).
2. Divide the topic pages and record an owner in each section index.
3. Create an assigned issue for your page, then work on a branch.
4. Use the [simple page templates](reference/page-templates.md).
5. Have a teammate review your pull request, merge the work, and link the issue from your About page.

The instructor will provide due dates. Keep explanations short and specific. **The assignment page is the source of truth for requirements.**
