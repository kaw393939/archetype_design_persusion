# Page templates

[Home](../README.md) · [Assignment](../assignment.md)

Copy the appropriate outline into your page. Replace prompts and example paths with your actual content. Use short explanations and useful images.

## Topic page

Use this for an archetype, persuasion principle, or design style.

```markdown
# Topic name
[Back to this section](README.md) · [Home](../README.md)

## What is it?
A short explanation. Add historical context for a design style.

## How do you recognize or use it?
Key characteristics, audience, and practical uses.

## Examples
Show each example and explain what it demonstrates.

## Sources
Direct source links and image credits.
```

| Page type | Examples to include |
|---|---|
| Archetype | Two original hero designs: one modernist, one postmodernist. Third optional. |
| Persuasion | One concrete application, such as headline and CTA, explaining the mechanism. |
| Design style | Two historical works with creator, title, date, institution, source, and image credit/reuse terms. |

## Add a design example to an archetype page

```markdown
### Example 1
![Describe the design](../assets/heroes/explorer/modernist.png)

Archetype: Explorer
Style: [Name and link to the researched style]
Persuasion: [Principle]
Headline: [Exact text]
CTA: [Exact text and intended action]

Explain how the archetype, style, and persuasion work together
in two or three sentences. Label generated imagery and credit sources.
```

Repeat for a postmodernist example. Replace `explorer/modernist.png` with your saved image path.

## About page

Create `members/first_last.md`:

```markdown
# First Last
[About the team](README.md) · [Home](../README.md)

## About me
A short introduction: interests, background, or goals.

## My issues and contributions
- [Issue title](PASTE_ACTUAL_ISSUE_URL) — In progress or completed;
  one sentence explaining my contribution.

## What I learned
A short reflection with a specific example from this project.

## Credits
Credit teammates for shared work or help, where appropriate.
```

If you have not started work, say so and add issue links as you begin.
