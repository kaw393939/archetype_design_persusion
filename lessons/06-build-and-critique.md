# Build and critique your design examples

**Optional help.** [Current assignment requirements](../assignment.md) · [Tutorial index](README.md)

[Optional tutorials](README.md) · [Home](../README.md) · [Assignment](../assignment.md)

This optional walkthrough helps with the two required designs per archetype. It creates no additional deliverables.

## Start with the message

Choose an audience, archetype, brand or offer, and intended action. Write a headline and CTA before generating imagery. Select one researched modernist style and one postmodernist style. Name the persuasion principle you intend to show in each.

Sketch where the headline, image, and button will go. Ask a teammate to explain the offer from the sketch.

## Give AI a clear request

```text
Create a static website hero design.
Audience:
Brand and archetype:
Offer and intended action:
Persuasion principle and how it appears:
Design style and features from my research:
Image subject and medium:
Exact headline and CTA:
Keep the text readable and the CTA clear.
Do not invent testimonials, statistics, or urgency.
```

Make the second example using the other design category. Keep the same brand or offer to make comparison easier. Saving prompts or drafts can help you work, but submitting them is not required.

## Check the result

Read every generated word. Check that the image makes sense and supports the message. Correct the copy or layout in a design tool if needed.

Ask a teammate: What is offered? Who is it for? What would the button do? Use their response to improve the design. This is a comprehension check, not proof of conversion.

Save the final image and add the labels and two- or three-sentence explanation required by the assignment. Commit the page and its images together for review.
